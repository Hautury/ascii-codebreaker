# ASCII Code Breaker

A Python project demonstrating ASCII-based encryption, decryption, and dictionary attack techniques.

## Features

- Convert text to ASCII and ASCII to text
- Encrypt messages using modular arithmetic
- Decrypt encrypted messages
- Automatically extend encryption keys
- Perform dictionary attacks to recover unknown keys
- Evaluate decrypted messages using English word scoring

## Technologies

- Python
- Jupyter Notebook

## Topics

- Cryptography
- ASCII Encoding
- Dictionary Attack
- File Processing
- Algorithms
